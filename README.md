# CollabFlow

Multi-Tenant Real-Time Team Collaboration SaaS.

## Overview

CollabFlow is a SaaS platform where organizations can manage:

- Teams
- Projects
- Epics
- Tasks
- Subtasks
- Files
- Comments
- Notifications
- Analytics
- Members

The system uses a multi-tenant architecture so multiple organizations can use the same application while their data remains isolated.
